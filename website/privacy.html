Privacy Summary: SWAYAM-GPT is an on-device Edge AI assistant designed to prioritize local execution, hardware-backed memory encryption, and auditable routing. We do not sell your personal data, operate third-party advertising trackers, or access your data without your consent.

1. Introduction & Scope

This Privacy Policy describes how [LEGAL ENTITY NAME] ("we", "our", or "us") handles information within the SWAYAM-GPT mobile application for Android (Application ID: com.mitsara.swayam).

This policy is constructed directly from the technical implementation of our Android source code, detailing the exact data types collected, stored, processed, and transmitted during application usage.

2. Information Processed & Stored Locally

SWAYAM-GPT maintains a local SQLite database (via Android Room) named edgeai_core_database.db on your device. The following data is processed and stored on-device:

  • Personal Memories & Notes: Sticky notes, observations, task notes, and tags created by the user or synthesized by local memory routines.
  • Hardware-Backed Encryption: Sensitive notes and personal memory entities are encrypted at rest using 256-bit AES-GCM (AES/GCM/NoPadding) with master keys stored securely inside the AndroidKeyStore Hardware Trusted Execution Environment (TEE).
  • Knowledge Base & Document Chunks: User-imported documents, text notes, and their local chunking vectors for Retrieval-Augmented Generation (RAG).
  • Action Items & Tasks: Task titles, priority levels, categories, and completion states.
  • Privacy Preferences: User configuration toggles (Offline-Only Mode, Cloud AI opt-in, Private Server opt-in, Vault Lock) stored in Android Jetpack DataStore (edge_ai_privacy_prefs).
  • Audit Records: A local log of AI routing decisions and policy validations, allowing users to verify whether requests were processed locally or remotely.

3. Device Permissions & Sensor Usage

The application requests only permissions essential to its core functions:

Permission Purpose Data Transmission Behavior
CAMERA Used for live MediaPipe perception, document scanning, object detection, and visual capture. Processed in local device memory. Camera frames are not transmitted unless explicitly submitted by you as an image query when Cloud AI is enabled.
RECORD_AUDIO Used for the Audio Journal feature, voice notes, and local speech transcription. Audio recordings are stored strictly on-device in app-private storage.
INTERNET & ACCESS_NETWORK_STATE Used for optional Google Gemini cloud inference and user-configured Private Server connections. Network calls are strictly blocked whenever Offline-Only Mode is enabled in Privacy Settings.
ACCESS_FINE_LOCATION & ACCESS_COARSE_LOCATION Used by the Context Engine to provide local environmental context (e.g. ambient weather and time). Location data is evaluated locally and is never sold, shared, or sent to advertising networks.
POST_NOTIFICATIONS Used to post scheduled reminders, routine notifications, and system status alerts. Generated locally on-device.

4. AI Inference Routing & Network Transmissions

SWAYAM-GPT utilizes a 3-tier hybrid AI routing architecture managed by the PrivacyEngine:

  1. On-Device AI (LiteRT / MediaPipe): Inferences are executed locally using on-device models. No data leaves your device.
  2. Private Server Gateway (Self-Hosted): If you configure a custom private server endpoint (e.g., local LAN vLLM or private cluster), encrypted HTTPS requests are transmitted directly to your designated gateway.
  3. Cloud AI Fallback (Google Gemini): When you explicitly enable Cloud AI and submit queries, requests are transmitted via HTTPS to the Google Gemini API (https://generativelanguage.googleapis.com) using your configured API key. The transmitted payload includes your prompt, relevant retrieved context, and system instructions.
  4. Offline-Only Mode: When active, the Privacy Engine strictly enforces socket blocking, rejecting all external network transmissions regardless of task type.

5. Diagnostics & Telemetry

SWAYAM-GPT implements a zero-tracking, privacy-guarded local telemetry provider (LocalAnalyticsProvider):

  • Telemetry measures UI tool usage frequency (e.g. Copy, Translate, Export, Voice Mic count) solely to render on-device usage visualizations in the application console.
  • Sanitization Rule: The telemetry layer programmatically inspects and strips all prompt text, images, memory contents, and authentication tokens before recording any metric.
  • Metrics remain on your device and are not uploaded to central analytics brokers.

6. Third-Party Services & SDKs

The application integrates standard Android platform dependencies:

  • Google Play Services / Firebase: Included for core platform integrity (Firebase App Check) and app distribution.
  • Google Generative AI (Gemini): Used strictly when Cloud AI is enabled by the user. Subject to Google's Privacy Policy.
  • No Advertising SDKs: There are no third-party advertising SDKs (such as AdMob, Unity, or Meta Ads) included in SWAYAM-GPT.

7. Data Retention, Control & Deletion

Because your data is stored locally on your device, you have complete control over its retention:

  • In-App Deletion: You can delete individual memories, clear document indexes, or reset the local database from the application settings.
  • Audit Log Clearing: Local privacy audit records can be purged at any time via the Privacy Center.
  • Complete App Data Removal: Clearing the application storage via Android System Settings or uninstalling the app permanently removes all database files, preferences, and hardware encryption keys.

8. Children's Privacy

SWAYAM-GPT is not directed to individuals under the age of 13 (or the applicable legal age in your jurisdiction). We do not knowingly collect personal information from children.

9. Security Measures

We implement industry-standard security safeguards, including:

  • Hardware-backed AES-256-GCM encryption for personal memory storage.
  • Mandatory TLS 1.3 encryption for all external HTTPS network communication.
  • Strict sandboxing of Model Context Protocol (MCP) tools to prevent arbitrary shell command execution.
  • ProGuard / R8 code shrinking and resource obfuscation in release builds.
