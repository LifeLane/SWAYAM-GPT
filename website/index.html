Core Ecosystem

Engineered for True Edge Intelligence

SWAYAM-GPT unites localized neural weights, hardware cryptography, and open agent protocols.

On-Device LiteRT Inference

Executes Gemma 2B and DeepSeek R1 models locally via Android LiteRT-LM runtime with zero cloud egress and sub-second token latency.

Hardware AES-256 Vault

Your personal memory notes, embeddings, and conversation histories are encrypted with Android KeyStore master keys in SQLite Room.

Real-Time Persona Chain ⛓️

Swap between 10 specialized personas in real-time or chain them dynamically (Code Architect ➔ Research Scout ➔ Tools Agent) for complex tasks.

Model Context Protocol (MCP)

Standard MCP JSON-RPC protocol exposing 17 Android tools (telemetry, contacts, calendar, file search, web retrieval) through governed gates.

Document Intelligence (RAG)

On-device semantic document search, PDF parsing, chunking, and cosine similarity vector retrieval with tamper-evident audit logs.

Transparent Privacy Engine

Every inference records an Explainability Certificate detailing what occurred, why, confidence scores, and which data sources were utilized.
