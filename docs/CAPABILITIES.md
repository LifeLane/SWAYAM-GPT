# Capability Discovery & Agent Profiles

Capabilities bridge high-level agent intents with concrete tool implementations.

## Agent Profiles

EdgeAI Core defines specialized operational profiles:

1. **`ASSISTANT`**: General-purpose everyday assistant with balanced capabilities.
2. **`MEMORY`**: Specialized for knowledge recall, fact memorization, and vector search.
3. **`VISION`**: Optimized for real-time camera perception, object tagging, and spatial understanding.
4. **`COACH`**: Focused on habit formation, wellness reminders, and health guidance.
5. **`STUDY`**: Academic learning, research assistance, and document summarization.
6. **`CREATOR`**: Idea brainstorming, content drafting, and creative ideation.
7. **`PRODUCTIVITY`**: Calendar coordination, task prioritization, and schedule management.
8. **`TRAVEL`**: Itinerary planning, weather tracking, and local information.
9. **`LIFE`**: Routine automation, device settings, and personal lifestyle tracking.
